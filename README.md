# Análise da digitalização de microempreendedores no Brasil

Projeto acadêmico de extensão desenvolvido no contexto do curso de Análise e Desenvolvimento de Sistemas (ADS), com foco na investigação da presença e do uso de tecnologias digitais por microempreendedores.

> **Status:** material acadêmico em desenvolvimento. O repositório contém a etapa inicial de diagnóstico e planejamento, além de planilhas de dados. A análise em Python e seus resultados ainda não estão documentados nesta versão pública.

## Objetivo

Investigar aspectos da digitalização de pequenos negócios e compreender como ferramentas digitais podem apoiar sua visibilidade, relacionamento com clientes e organização.

O recorte inicial considera microempreendedores e pequenos estabelecimentos no estado do Rio de Janeiro.

## Escopo registrado

- Identificação das partes interessadas e do contexto do problema.
- Formulação da problemática relacionada à presença digital.
- Justificativa e objetivos do projeto de extensão.
- Referencial teórico sobre transformação digital, marketing e inclusão digital.
- Organização inicial de planilhas para uma etapa posterior de análise.

## Estrutura do repositório

- `projeto_analise_meis.ipynb`: notebook com o diagnóstico, a justificativa, os objetivos e o referencial teórico inicial.
- `dados/`: planilhas utilizadas como material de apoio para a etapa de análise.

## Tecnologias e ferramentas previstas

- **Python** para análise e tratamento de dados.
- **Pandas** para manipulação de tabelas.
- **Matplotlib** para visualização.
- **OpenPyXL** para leitura de planilhas Excel.

Essas ferramentas fazem parte do planejamento inicial. Este README não afirma que uma análise completa ou gráficos finais já tenham sido produzidos.

## Observações metodológicas

A presença digital de MEIs não deve ser inferida apenas a partir de dados gerais de empresas ou de indicadores agregados. Antes de tirar conclusões, é necessário verificar se as planilhas representam de fato o público, o período e os indicadores descritos no objetivo do projeto.
